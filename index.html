CRISP-DM Framework Implementation

This research and computational workflow follows the standard CRISP-DM (Cross-Industry Standard Process for Data Mining) methodology.

Phase 1
Business Understanding
Identify the key corporate spending channels (R&D, Marketing, Admin) that drive startup profitability. Determine whether regional location or overhead expenses justify their model complexity costs.
Phase 2
Data Understanding
Examine the 50 observations across 5 features. Confirm data integrity (0 missing values), identify right-skewed revenue distributions, and inspect pairwise correlation matrices (R&D and Profit correlation r = 0.97).
Phase 3
Data Preparation
One-hot encode categorical variable 'State' with California as reference category. Perform 80/20 train-test split (random_state=0) and standardized feature scaling for regularization methods.
Phase 4
Modeling & Feature Selection
Systematically execute 6 feature selection algorithms: Lasso (L1), Forward Stepwise (SFS), RFE, ElasticNet, Ridge (L2), and Exhaustive Best-Subset search across all subset sizes k ∈ [1, 5].
Phase 5
Evaluation & Occam's Razor
Discover the optimal k=2 sweet spot (['R&D Spend', 'Marketing Spend']) with minimum test RMSE ($8,198.80) and peak R² (0.9474). Observe the k=5 overfitting cliff where redundant parameters increase error by +$939.
Phase 6
Deployment
Deploy this dual-mode application supporting both serverless static execution on GitHub Pages and high-throughput Python Flask REST API with interactive scenario simulation.
